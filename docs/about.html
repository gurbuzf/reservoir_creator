Method

The method was developed by Faruk Gurbuz in Reservoir Creator 1.0 (2021): water level from the dam line, reservoir behind it, elevation–area–volume from the DEM. Version 2 finds the reservoir extent directly on the DEM instead of from a contour layer (details).

The connectivity step uses the Priority-Flood technique: Barnes, R., Lehman, C., Mulla, D. (2014). Priority-Flood: an optimal depression-filling and watershed-labeling algorithm for digital elevation models. Computers & Geosciences 62, 117–127. DOI

Development

core/    engine: numpy + GDAL, no Qt (unit tested)
gui/     QGIS panel, charts, background task, exports
tests/   pytest suite + whole plugin in a real QGIS (offscreen)
make test     # unit tests
make smoke    # whole plugin inside QGIS
make zip      # installable plugin package

Translations: every visible string goes through tr(); Turkish text lives in core/i18n_tr.py, and a test fails if one is missing.
