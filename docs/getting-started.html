Get started

Install and run your first reservoir

Five minutes with the sample data included in the repository.

Install

Plugin manager

Plugins ▸ Manage and Install Plugins, search Reservoir Creator. Tick Show also experimental plugins in Settings.

ZIP

Download the repository ZIP, then Install from ZIP.

From source

Clone the repository into your profile's python/plugins folder (or link it there).

Needs numpy, GDAL and matplotlib, all shipped with QGIS on Windows and macOS. On Linux install python3-matplotlib if it is missing.

First run with the sample data

Load the data

Add data/dem_utm37.tif and data/dam_line.shp to a project (EPSG:32637).

Open the panel

Click the Reservoir Creator toolbar button. It opens as its own window; Dock attaches it to QGIS.

Set the line

Step 1: From layer ▸ dam_line. Or Draw on map and click across the valley, right-click to finish.

Set the DEM

Step 2: Project layer ▸ dem_utm37.

Create reservoir

Press the blue button at the bottom of the panel.
