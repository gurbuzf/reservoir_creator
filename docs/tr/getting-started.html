Kurulum

Henüz resmi QGIS eklenti deposunda değil: GitHub'dan kurun.

ZIP'i indir GitHub'da aç

ZIP'i indirin

Yukarıdaki düğme ya da GitHub'da: Code ▸ Download ZIP. Dosyayı açmayın.

ZIP'ten yükleyin

QGIS'te: Eklentiler ▸ Eklentileri Yönet ve Yükle ▸ ZIP'ten Yükle (Plugins ▸ Manage and Install Plugins ▸ Install from ZIP), dosyayı seçin, Eklentiyi Yükle. Güvenlik uyarısını onaylayın.

Açın

Yüklenenler (Installed) altında Reservoir Creator işaretli olsun; düğmesi araç çubuğunda görünür.

QGIS 3.28 ile 4.x arası · Windows, macOS, Linux. Güncellemek için en yeni ZIP'i aynı şekilde yükleyin.
